# Resources Directory

This directory contains images and other resources used in the iPA documentation.

## Image Guidelines

When adding images to the documentation:

1. **File formats**: Use PNG for screenshots and diagrams, JPEG for photographs
2. **Resolution**: Use high DPI images (300 DPI) for print quality
3. **Size**: Keep file sizes reasonable (<2MB per image)
4. **Naming**: Use descriptive names with underscores: `ipa_workflow_example.png`

## Required Images

The following images are referenced in the documentation but need to be created:

- `ipa_workflow_example.png` - Overview of iPA analysis pipeline
- `partitioning_example.png` - Radial cytoplasmic partitioning visualization
- `spatial_analysis.png` - Organelle spatial analysis results
- `interaction_mapping.png` - Multi-organelle interaction networks
- `cryoet_processing.png` - CryoET data processing workflow

## Creating Images

Images can be generated from:

- Analysis results and plots from iPA
- Matplotlib/plotly visualizations
- Screenshots of analysis outputs
- Schematic diagrams of workflows

## Image Attribution

If using external images or adapting figures from publications, ensure proper attribution and licensing compliance.
