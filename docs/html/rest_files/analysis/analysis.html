Analysis Module

The analysis module provides comprehensive tools for quantitative analysis of cellular imaging data across multiple microscopy modalities.

Overview

This module contains specialized analysis tools for different imaging techniques:

  • SXT Analysis: Radial Distribution Function (RDF) analysis and spatial organization for Soft X-ray Tomography data

  • Cryo-ET Analysis: Actin-organelle interaction analysis and spatial relationship quantification for Cryo-Electron Tomography

  • SIM/WFM Analysis: Morphological measurements and multi-organelle interaction analysis for Structured Illumination and Widefield Microscopy

The analysis module supports:

  • Statistical analysis of cellular features

  • Morphological measurements

  • Distance and angular distribution analysis

  • Spatial relationship analysis

  • Multi-organelle interaction analysis

  • Organelle feature extraction

  • Temporal dynamics analysis

  • Radial distribution function calculations
